# Проверка статического сайта

Дата проверки: 31 августа 2026 года.

## Реализовано

- удалены сервер, API, база данных, загрузки и код передачи сообщений;
- публикация референсов согласована владельцем материалов;
- удалён весь клиентский JavaScript;
- отсутствуют формы и элементы ввода;
- отсутствуют аналитика, рекламные пиксели, сторонние виджеты и iframe;
- политика безопасности запрещает скрипты, сетевые подключения страниц и отправку форм;
- браузер не передаёт внешний referrer;
- внешние ссылки используют `noopener` и `noreferrer`;
- автоматический тест контролирует сохранение этих ограничений.

## Перед публикацией

- публиковать только файлы, которые копирует workflow GitHub Pages;
- отключить в панели хостинга автоматическую подстановку аналитики, если такая функция включена;
- проверить настройки хранения технических журналов доступа;
- не добавлять код счётчиков и сторонние виджеты без отдельной оценки.
