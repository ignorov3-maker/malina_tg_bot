# Статический сайт типографии «Малина»

Информационный сайт без серверной части и механизмов приёма обращений.

## Что входит в сайт

- описание услуг и примеры выполненных работ;
- адрес офлайн-типографии;
- обычные внешние ссылки на корпоративные страницы во ВКонтакте и MAX;
- отдельная страница со всеми визуальными референсами;
- отдельная страница с информацией о конфиденциальности.

На сайте нет форм, полей ввода, встроенного чата, загрузки файлов, JavaScript, API, базы данных, аналитики, рекламных пикселей и необязательных cookie.

## Файлы для размещения на Beget

В публичную папку сайта загрузите только:

- `index.html`;
- `privacy.html`;
- `references.html`;
- `styles.css`;
- папку `assets` целиком.

Остальные файлы относятся к разработке и не нужны на хостинге.

## Проверка

Требуется Node.js 20 или новее:

```text
npm test
```

Проверка подтверждает отсутствие форм, скриптов, сетевых API, хранилищ браузера, аналитики и встроенного стороннего содержимого. Она также проверяет защитные атрибуты внешних ссылок, наличие всех референсов и политику безопасности страниц.

## Важное ограничение

Если позже добавить форму, обратный звонок, встроенный чат, аналитику, рекламный пиксель, карту, сторонний виджет или уникальные метки для отслеживания переходов, конфигурацию конфиденциальности нужно пересмотреть до публикации.
