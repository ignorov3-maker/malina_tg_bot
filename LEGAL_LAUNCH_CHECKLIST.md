# Контрольный список для статического сайта

Этот список относится только к текущей версии сайта без приёма обращений.

- [x] Нет форм, полей ввода и загрузки файлов.
- [x] Нет личного кабинета, регистрации и авторизации.
- [x] Нет JavaScript, API и базы данных.
- [x] Нет аналитики, рекламных пикселей и необязательных cookie.
- [x] В опубликованных фотографиях нет узнаваемых заказчиков, персональных подписей, телефонов и QR-кодов третьих лиц.
- [x] Внешний справочный сервис открывается обычной ссылкой и не встроен в сайт.
- [x] Сервис обозначен как независимый и не принимающий заказы от имени типографии.
- [x] Заказы направляются только в офлайн-типографию.
- [x] Опубликована точная информация о конфиденциальности текущей версии сайта.
- [ ] В панели Beget проверены сроки хранения и доступ к техническим журналам сервера.
- [ ] После загрузки проверено, что хостинг не добавил сторонние счётчики или скрипты.

Любое добавление формы, онлайн-заказа, обратного звонка, клиентской базы, аналитики, рекламного пикселя или встроенного стороннего сервиса требует новой технической и юридической проверки до запуска.
